# 通达信选股公式（由 tdx-formula 技能生成）

**生成日期：** 2026-08-13

## 导入方法

1. 通达信按 `Ctrl+F` 打开公式管理器。
2. 条件选股公式（公式 ① ②）：选择「条件选股公式」→「新建」，粘贴代码，命名保存。
3. 专家系统公式（公式 ③）：选择「专家系统公式」→「新建」，粘贴代码，命名保存。
4. 选股：`Ctrl+T` 打开条件选股，勾选公式 →「执行选股」。

## ① MACD 趋势共振选股（条件选股公式）

```
{ 公式名称: MACD趋势共振 }
{ 公式描述: 60日线向上+股价站上60日线+MACD 0轴上方金叉/红柱放大+量比放大 }
MA20:=MA(CLOSE,20);
MA60:=MA(CLOSE,60);
DIF:=EMA(CLOSE,12)-EMA(CLOSE,26);
DEA:=EMA(DIF,9);
MACD:=(DIF-DEA)*2;
非ST:=IF(NAMELIKE('S'),0,1) AND IF(NAMELIKE('*'),0,1);
非停牌:=DYNAINFO(8)>0;
趋势合格:=MA60>REF(MA60,5) AND CLOSE>MA60 AND MA20>MA60;
金叉:=EXIST(CROSS(DIF,DEA),3) AND DIF>0;
红柱放大:=MACD>0 AND MACD>REF(MACD,1) AND DIF>DEA;
节奏:=金叉 OR 红柱放大;
量能:=DYNAINFO(17)>=1;
选股:趋势合格 AND 节奏 AND 量能 AND 非ST AND 非停牌;
```

说明：先过滤 ST/停牌 → 均线定方向（MA60 向上、股价在其上、MA20>MA60）→ MACD 定节奏（0 轴上方金叉或红柱重新放大）→ 量比过滤。

注意：`DYNAINFO(17)` 量比为实时数据，盘中选股才有效；盘后可用 `VOL/MA(VOL,5)>1.2` 替代。

## ② 回踩 MA20 企稳选股（条件选股公式）

```
{ 公式名称: 回踩MA20企稳 }
{ 公式描述: 中期多头排列中，股价回踩MA20后今日收回且缩量企稳 }
MA20:=MA(CLOSE,20);
MA60:=MA(CLOSE,60);
DIF:=EMA(CLOSE,12)-EMA(CLOSE,26);
DEA:=EMA(DIF,9);
MACD:=(DIF-DEA)*2;
非ST:=IF(NAMELIKE('S'),0,1) AND IF(NAMELIKE('*'),0,1);
非停牌:=DYNAINFO(8)>0;
趋势:=MA20>MA60 AND CLOSE>MA60 AND MA60>REF(MA60,5);
回踩:=LLV(LOW,5)<=MA20*1.015;
企稳:=CLOSE>MA20 AND CLOSE>REF(CLOSE,1);
动能:=DIF>=DEA OR MACD>REF(MACD,1);
缩量:=VOL<MA(VOL,5)*1.2;
选股:趋势 AND 回踩 AND 企稳 AND 动能 AND 缩量 AND 非ST AND 非停牌;
```

说明：趋势约束防逆势抄底；回踩范围 ±1.5%（`1.015` 可改）；要求收盘收复 MA20、动能未走坏、缩量企稳。

## ③ 均线趋势跟随买卖系统（专家系统公式）

```
{ 公式名称: 均线趋势跟随 }
{ 公式描述: MA5上穿MA10且站上MA20买入，MA5下穿MA10卖出 }
MA5:=MA(CLOSE,5);
MA10:=MA(CLOSE,10);
MA20:=MA(CLOSE,20);
ENTERLONG:CROSS(MA5,MA10) AND CLOSE>MA20;
EXITLONG:CROSS(MA10,MA5);
```

说明：标准趋势跟随，金叉站上 MA20 才买、死叉就卖。震荡市会被反复打脸，建议叠加 60 日线方向过滤。

## 通用注意事项

- 三条公式均**不含未来函数**（ZIG/BACKSET/REFX 等），可用于选股和回测。
- 公式内所有标点为英文半角，语句以分号结尾；注释用 `{ }`。
- 回测/选股结果仅供参考，不构成投资建议。
